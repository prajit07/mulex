        Transaction CSV

        Required columns id,sender,receiver,amount_paise,timestamp. Extra columns are dropped automatically and each distinct endpoint becomes an account.

        Column Rule Example
        id Unique transfer ID T1
        sender, receiver Account IDs, case-sensitive, distinct A, B
        amount_paise Positive integer INR paise 125050 (= ₹1,250.50)
        timestamp ISO 8601 with timezone offset 2026-11-01T09:00:00+05:30

        Full JSON dataset

        name, accounts (id, name, optional device), transactions and optional complaints (id, account, category, timestamp, optional transfer involving that account). Extra fields are dropped during schema validation.

        • Up to 3,000 accounts
        • Up to 20,000 transfers
        • Up to 5,000 complaints
        • UTF-8, 4 MB per file
